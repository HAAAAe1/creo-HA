# H — Creo 工具箱（球标 / 注释 / 尺寸 / 3D / 导出）

<https://github.com/user-attachments/assets/3c779267-59cf-414f-9932-e56859ec0e5a>

在 Creo 里干活的一站式 TOOLKIT 插件。装好后功能区多一个 **「HA」** 页签：

- **工程图**：7 个组 —— 注释 · 球标 · 工程图 · 绘图比例 · 模型信息 · 会话操作 · 导出
- **零件 / 装配 / 钣金 / 启动页**：6 个组 —— 会话操作 · 模型信息 · 着色 · 视图 · 简化助手 · 基准

球标编号、技术要求、重点尺寸、一键导出、视图动态调整、公差刷子、绘图比例、会话操作、
3D 模型处理全在一个页签里；连 Creo 原生的绘图「注释」命令也搬了过来，出图时不用在
「注释」和「HA」之间来回切。

- ✅ **一份 DLL 通吃 Creo 6.0 ~ 12.0**（用 Creo 6.0 Toolkit 编译，PTC 官方保证旧版编译的程序可在更新版本上运行）
- ✅ **加载后功能区自动出现「HA」选项卡**，不用手工拖按钮
- ✅ **路径全自动**：插件运行时自查所在目录，整个文件夹拷到哪都能用
- ✅ **不依赖 BOM 表**：球标是纯独立符号实例，想怎么排就怎么排
- ✅ **链接即用**：发布包里的 `H.dll` 已用 PTC 官方 `protk_unlock` 盖过章，拿到装上就能加载，不会弹「未解锁」

> 只想看有什么功能、怎么用：打开 [`功能说明.txt`](功能说明.txt)，一页看完。

## 功能一览（工程图页签）

### 注释（9 项，全部是 Creo 原生命令，插件零实现代码）

不是自己写的新功能，而是**直接把 Creo 绘图「注释」页签上的按钮搬过来**——
图标、文字、灰化状态、自带的下拉，全部由 Creo 自己提供，行为和原生页签完全一致。

| 按钮 | 挂的系统命令 |
| --- | --- |
| 尺寸（组里唯一的大按钮） | `ProCmdDwgCrStdNewRefDim` |
| 几何公差 | `ProCmdDwgCrGtolSpecTol` |
| 纵坐标尺寸 | `ProCmdDwgCrOrdDim` |
| 注解 ▾（分离 / 偏移 / 顶上 / 引线，4 项） | `ProCmdDtlInsFreeNote` 等 4 个 |
| 表面粗糙度 | `ProCmdDwgCreateSurfFin` |
| 显示模型注释 | `ProCmdDwgShowAllAnnots` |
| 设置基准（基准要素符号） | `ProCmdDwgCrGtolSetDtm` |
| 绘制基准目标 | `ProCmdDwgCrGtolMakeTarg` |
| 绘制基准平面 | `ProCmdDwgCreateDrftDatum` |
| 绘制基准轴 | `ProCmdDwgCreateDraftAxis` |

> 这些命令名是从 `<Creo 安装目录>\Common Files\text\compiled_resource\pro_default_resources.dll`
> 里提取的（Creo 12 有 6308 个、Creo 6 有 5201 个，**两版交集 5174 个**）。
> 本组用到的命令全部落在交集里，所以 **Creo 6 和 Creo 12 都能用**。
> 插件启动时还会用 `ProCmdCmdIdFind` 逐个验证，结果写在 `h_load.log` 里
> （`native cmd <名字> -> <指针> [FOUND]`），某个名字缺失会显示 `[MISSING]`。

### 球标（6 项）

| 按钮 | 行为 |
| --- | --- |
| **添加球标** | 点图纸位置放一个圆圈球标，编号取当前最大号 +1。**连续放置**：放完一个直接点下一个位置，全部放完按鼠标中键 / 右键 / Esc 结束 |
| **插入球标** | 先点放置位置，再点一个已有球标；新球标就用那个编号，它以及比它大的号全部自动 +1 |
| **删除球标** | 点选要删除的球标，删除后其余序号自动重排补齐 |
| **重排序号** | 把所有球标压实成 1、2、3…（补齐删除留下的空号） |
| **重点尺寸** | 连点尺寸，点一个标一个，在该尺寸文本**前面**加 ★（中键 / Esc 结束） |
| **取消重点尺寸** | 同样连点尺寸，把前缀里的 ★ 去掉 |

**重点尺寸的约定**：已有 ★ 的自动跳过（幂等，不会叠成 ★★20）；原前缀会保留（`2x` → `★2x`）；
参考尺寸 / 从动尺寸改不动，会提示跳过。

> 实现走的是**尺寸前缀** `ProDimensionPrefixSet`，不是改尺寸文本。前缀是独立字段，
> 数值文本原样保留，在 Creo 里右键 Properties 也能看到并手工改。

典型场景 —— 图纸上已排好 1~18 号，发现漏了一个尺寸要插在 12 号前面：
点「插入球标」→ 点新尺寸旁的放置位置 → 点现在显示 12 的那个球标。
新球标自动变成 12 号，原 12~18 全部变成 13~19 号，位置都不用动，一次点完。

### 工程图（5 项）

| 按钮 | 行为 |
| --- | --- |
| **原位打开** | 选中一个视图，**按这个视图的方向**把 3D 模型单独开窗（方向取自 `ProDrawingViewTransformGet`，详见下方说明） |
| **打开 3D** | 打开当前图纸关联的 3D 模型（单独窗口） |
| **公差刷** | 刷子式两步：① 点选**源尺寸**（Esc 退出）——选到参考 / 从动尺寸会提示重选；② 逐个点选接收公差的尺寸，点一个刷一个，个数不限，**中键 / Esc 结束**。刷入 = 公差类型（公称 / 基本 / 极限 / 正负 / 对称 / 对称上标）、上 / 下公差值、ISO/DIN 公差表、公差小数位，逐项原样复制。**不做「按名义尺寸换算极限」**：这些接口取回的就是公差值本身，换算反而会算错。公差要可见需 config `tol_display yes` |
| **技术要求** | 点按钮 → Creo 原生文件浏览器（默认停在插件目录的 `templates\技术要求`）→ 选一个 `.txt` → 消息行提示点放置位置 → 左键点一下，**整个文件变成一条多行注解**，可整体拖动。空行保留（显示为一行空白）。**每行最多 80 字**（超出截断）、**一个模板最多 64 行**。编码支持 UTF-8（带不带 BOM 都行）和 ANSI/GBK |
| **视图动态调整** | ① 弹 Creo 原生「选择」对话框（悬停高亮 + 「数据 视图」提示）选中一个普通视图；② **直接移动鼠标就能全方位旋转该视图**，水平移 = 绕竖直轴、垂直移 = 绕水平轴；**中键确认**，**Esc 取消并精确复原**。走 `ProSelect("dwg_view")` + `ProDrawingViewOrientationFromAngleSet(…, "Horizontal"/"Vertical", NULL, 增量角)`——绕**过视图原点、相对图纸固定**的轴做**增量旋转**，不需要基准视图，所以进入时视图原地不动（零跳变），可连续累积、可逆。只接受**普通视图（General）**，投影 / 详图 / 剖视等派生视图会被拒绝并提示 |

> **「原位打开」的方向怎么来的**：`ProViewMatrixGet` 对图纸视图**恒返回 -1**（选择集句柄和
> `ProDrawingViewInit` 换出来的正式句柄都一样），所以早期版本只能「开窗但不套方向」。
> 现在改用 `ProDrawingViewTransformGet(drawing, view, PRO_B_TRUE, m)`——官方示例
> `UgDrawingDimensions.c` / `TestDrwView.c` 用它把模型里的 3D 点换算成图纸上的 2D 点，
> 故其左上 3×3 即「模型 → 图纸」的完整朝向；行归一化去比例、末行清零去平移后交给
> `ProViewMatrixSet`。原来的两条 `ProViewMatrixGet` 保留作兜底。

### 绘图比例（6 个常用档 + 更多 20 档）

```
1:1   1:2   1:3      ┌ 更多比例 ▾ ┐
2:1   3:1   4:1      │  1:4       │
                     │  …22 档…   │
                     │  自定义比例 │
                     └───────────┘
```

全部按 HelloCreo 的 25 档对齐：`1:1 1:2 1:3 1:4 1:5 1:6 1:8 1:10 1:12 1:15 1:20`
`2:1 3:1 4:1 5:1 6:1 8:1 10:1 12:1 15:1 20:1 2:3 2:5 3:2 5:2`。

**自定义比例**：在消息行里输入，支持 `1:2.5`、`2.5:1`、`0.4`、`1/3` 和全角冒号。

### 模型信息（3 项，工程图 / 零件 / 装配通用）

| 按钮 | 行为 |
| --- | --- |
| **重命名** | 消息行输入新名字 → 重命名当前模型，**同名工程图跟着改** |
| **复制名称** | 当前名字复制到剪贴板：装配复制装配名、零件复制零件名、图纸复制图纸名，不用先选中 |
| **轮廓尺寸** | 弹窗列出当前模型的 X / Y / Z 外形尺寸（`ProSolidOutlineGet`，取不到时退回 `ProSolidOutlineCompute`），单位是模型单位 |

### 会话操作（8 项）

| 按钮 | 行为 |
| --- | --- |
| **打开工作目录** | 用资源管理器打开当前 Creo 工作目录 |
| **设置工作目录** | 弹出 Creo 原生目录浏览器，选中后切换工作目录 |
| **打开模型目录** | 用资源管理器打开**当前模型**所在文件夹 |
| **模型转目录** | 选一个目录，把会话里所有零件 / 装配 / 工程图备份进去（等同「文件 → 备份」） |
| **批量备份** | `ProMdlnameBackup`：当前模型**连同它引用的全部子模型**一起备份 |
| **批量删旧版** | 删工作目录下的 `.prt.N` / `.asm.N` / `.drw.N` / `.frm.N` / `.sec.N` / `.lay.N` / `.mfg.N` |
| **删除闲置模型** | 把没有显示在任何窗口里的模型从会话中移除 |
| **清理垃圾** | 删 `.err .out .inf .idx .xpr .bak .dwl .m_p .lst .tst` |

> **两个删除功能有安全限制**：先扫描计数 → 消息行提示「输入 Y 回车执行，直接回车取消」→ 才动手。
> 范围锁死当前工作目录、只认白名单扩展名、**不递归子目录**。
> 「批量删旧版」额外一条：**必须同目录存在无编号的同名文件才删**——
> 如果某个模型只剩 `.prt.3` 而没有 `.prt`，那份 `.3` 就是唯一副本，跳过不删。

### 导出（1 项）

**一键导出** —— 弹出 Creo 原生的「保存」文件浏览器：**在哪儿选目录、叫什么名字都随你**，Esc 取消。

- `<名字>.stp` —— 该工程图关联的 **3D 模型**（STEP）
- `<名字>.pdf` —— 工程图本身，**600 dpi + 单色**，导出后不弹阅读器
- `<名字>.dwg` —— 工程图本身（AutoCAD DWG）
- 若图纸没关联 3D 模型，只导 PDF 和 DWG 并给出提示
- **中文名没问题**：Creo 的 DWG 导出器不认中文名，所以插件先用固定的 ASCII 临时名导出到工作
  目录，再由插件改名搬到你要的位置（`MoveFileExW` + `MOVEFILE_COPY_ALLOWED`，宽字符）

## 功能一览（零件 / 装配 / 钣金 / 启动页的「HA」页签）

同一份选项卡定义在 `main_adb_cat` / `prt_main_adb_cat` / `asm_main_adb_cat` /
`prt_smt_main_adb_cat` 四个容器上各挂一遍，所以**不开工程图也能用**。会话操作与模型信息
两组和上面完全一样，下面只写剩下的四组。

### 着色（2 项）

| 按钮 | 行为 |
| --- | --- |
| **随机着色** | 给装配里每个元件分配不同颜色（黄金角递增，相邻色差最大）；同一零件的多个实例同色。零件则整体涂一个随机色。想保留记得存盘 |
| **清除着色** | `ProMdlVisibleSideAppearancepropsSet(…, NULL)` = 恢复默认外观 |

### 视图（2 项）

| 按钮 | 行为 |
| --- | --- |
| **原位打开** | 选一个元件，**按装配当前视角**把它单独打开（先 `ProViewMatrixGet` 记矩阵 → `ProMdlDisplay` → `ProViewMatrixSet` 套回去） |
| **视图正归位** | 选面就垂直于该面看，不选就摆到默认轴向视图，然后只按实体铺满窗口 |

### 简化助手（5 项）

**隐藏零件**（`ProModelitemHide`）/ **反隐藏零件**（`ProModelitemIsHidden` 判断后切换）/
**全部隐藏** / **全部显示**（`ProSolidFeatVisit` 遍历所有特征逐个处理——Creo 没有
HideAll / UnhideAll 的 C 接口）/ **显示**。

> **选择怎么做**：先**在图形区选中**要处理的对象，再点按钮 —— 插件直接读 Creo 的选择缓冲区，
> 不再弹选择。没预选时才进入交互选择，此时消息行会提示「点选对象，中键确认」。
> 这样和 Creo 自己「先选后点」的习惯一致。

### 基准（4 项）

**方程曲线**（用参数方程生成基准曲线，正弦波纹环 / 螺旋等；开放样条，要修剪先投影）/
**修剪** / **投影** / **扫描**（后三个是 Creo 原生命令：`ProCmdFtTrim` / `ProCmdFtProject` / `ProCmdFtLoft`）。

> **3D 模式下也能认工程图**：当前窗口不是 3D 时，插件自动改用这张图关联的模型
> （`ProDrawingCurrentsolidGet`），不用先切窗口。

## 快速安装（3 步，1 分钟）

1. **放置文件**：把整个 `H` 文件夹复制到纯英文、无空格的目录，例如 `D:\H`
   （放在别的位置先双击运行一次 `setup.bat`，它会自动修正注册文件里的路径）
2. **注册插件**：记事本打开 Creo 的 `config.pro`，最后加一行：
   ```
   protkdat D:\H\H.dat
   ```
   （放在别的目录就把路径换成实际位置；也可以在 Creo 里
   工具 → 辅助应用程序 → 注册 → 选中 H.dat → 启动，但只当次生效）
3. **重启 Creo**。打开任意工程图，选项卡栏最右侧出现「**HA**」选项卡，装好了。

> 如果点按钮提示「未找到球标符号文件」：看插件目录下自动生成的 `h_load.log`，
> 里面写明了原因（符号文件是否缺失、三条加载路径各自的返回码），把日志发给作者即可定位。

## 技术要求模板文件夹

`templates\技术要求\` 里每个 `.txt` 都会出现在选择列表里，文件名就是列表里看到的名称
（建议用 `01_`、`02_` 开头控制顺序）。**一行就是注解里的一行**，直接往这个文件夹里丢 txt 就行。

- 目录不存在时插件会自动创建；模板目录跟着插件文件夹走，换电脑不用改任何设置
- 包里自带 30 多个常用模板（车件 / 钣金 / MIM / 压铸锌合金 / 弹簧 / 工艺路线 / 齿轮参数…），按自己的工艺改就行
- 编码 UTF-8 或 ANSI(GBK) 都能读，行尾 CRLF / LF 都行
- ⚠ 每行超过 80 字会被截断，超过 64 行会被截掉——这是 Creo 注解单行的宽度限制（`PRO_LINE_SIZE = 81`）

## 故障排查

插件目录下每次启动都会写 `h_load.log`，关键行：

- `ProCmdActionAdd(...) -> 0`：0 = 命令注册成功（返回 -28 也不影响按钮功能，可忽略）
- `ProRibbonDefinitionfileLoad(...) -> 0`：功能区加载成功。
  `-4` = rbn 文件没找到（确认 `text\ribbon\toolkitribbonui.rbn` 存在）；`-16` = 格式不对
- `native cmd <命令名> -> <指针> [FOUND] / [MISSING]`：注释组那批原生命令名的存在性自检。
  全是 `[FOUND]` 说明这批按钮在当前 Creo 版本上一定可用
- `HLoadSymbol: ... EXISTS / MISSING!`：符号文件在不在。`MISSING!` 说明包不完整，少了 `symbols` 文件夹
- `HLoadSymbol: OK via [1|2|3]`：符号最终走通哪条加载路（1=pro_symbol_dir 相对路径，2=复制到工作目录，3=绝对路径兜底）
- `HTechReqAct: file open -> 0`：技术要求选了模板文件（`-1` = 用户取消）；`cp=/bom=/lines=` 是识别出的编码、有无 BOM、读到的行数
- `HExportAct: ...`：一键导出的逐步返回码。`STEP -> 0`、`DWG -> 0`、`PDF -> 0` 是成功；
  `HExport: moved -> <完整路径>` 表示临时文件已改名搬到你要的位置；
  行尾 `license_missing=1` 说明缺少对应导出模块的授权

常见现象：

- **提示「未找到球标符号文件」**：把 `symbols\123.sym` 复制到 Creo 当前工作目录，
  或在 `config.pro` 里设 `pro_symbol_dir D:\H\symbols`
- **提示「请在工程图界面执行此命令」**：这些命令只能在工程图（Drawing）模式下用
- **重点尺寸的 ★ 显示成方框**：当前绘图字体没有 ★ 字形。Creo 默认的 CJK 回退一般没问题，
  真遇到就在 `config.pro` 里换一款支持中文的绘图字体，或改用 `◆`
- **功能区没有「HA」选项卡**：先确认工程图模式；仍没有则按「自定义功能区」导出正规 rbn：
  `config.pro` 加 `tk_enable_ribbon_custom_save yes` 重启 → 文件 → 选项 → 自定义功能区 →
  导入/导出 → 保存辅助应用程序用户界面 → 把生成的 rbn 覆盖 `text\ribbon\` 下同名文件
- **页签/组名显示成英文键名（如 `H_Title`、`H_Annot`）**：功能区页签和组的标签只认
  `text\<locale>\ribbonui.txt`（命令标签才走 `h_msg.txt`），该文件缺失或没刷新就是这个现象
  （含中文的用 UTF-8 + BOM；英文那份纯 ASCII 无 BOM；行尾 LF）

## ⚠️ 发给别人之前：必须先解锁

别人打开 Creo 弹出「**应用程序 "H" 在分配到您的位置之前未被解锁**」，
不是插件写错，是 PTC 对 TOOLKIT 插件的统一规定：编译出的 DLL 默认锁定，
只有装了 Creo Parametric TOOLKIT 开发许可的电脑才能加载，分发前必须解锁。

**本仓库 release 里的 zip 已经解过锁**，拿到直接用就行。自己重新编译了才需要：

1. 完全退出 Creo（任务管理器确认没有 `xtop.exe`）
2. 双击 `开发资料\unlock.bat`，看到「解锁成功」即可
3. 打包发给别人

两条铁律：

- **每次重新编译 H.dll 之后都要重新跑一次 unlock.bat**（链接时会重新写入锁定标记）
- **解锁之后不要再改动 H.dll 哪怕一个字节**（改动后会被重新当成锁定状态）

> 踩过的坑：`protk_unlock` **处理不了中文路径**——`D:\H\开发资料\tmp\H.dll` 会被截断成
> `D:\H\` 然后报 `prolicense error … ERROR opening D:\H\`。所以 `unlock.bat` 会先把 DLL
> 复制到 `%TEMP%\h_unlock_work` 再解，并自动遍历本机所有 Creo 版本的 `protk_unlock.bat`
> 逐个试到返回 0 为止。Creo 6 的解锁器只认 31.0 级授权，用 Creo 12 的解锁器可以解用
> Creo 6 编译出来的 DLL。

## 球标符号版本注意（`symbols\123.sym`）

Creo 的文件只**向上兼容**：新版能读旧版，旧版读不了新版，`.sym` 一模一样。

- 本插件的 `123.sym` 用 **Creo 6.0.2.0** 存出（格式级别 3700），Creo 6~12 全能读
- **千万别用新版 Creo 打开它再保存** —— 保存会升级成新版格式，对方的 Creo 6 立刻读不了
- 以后换符号同理：发给谁，就用**对方那个版本或更老**的 Creo 去存

## 重新编译（可选）

需要 Visual Studio 2022（含 C++ 生成工具）和 Creo 6.0 的 Toolkit 开发包
（Creo 安装介质自带，没勾「API Toolkits / Creo Parametric TOOLKIT」组件的话用安装程序补装）：

1. 把 `makefile` 里 `CREO6_SDK` 改成 Toolkit 根目录（含 `includes` 与 `x86e_win64\obj`）
2. 双击 `build.bat`（或 `nmake /f makefile`）
3. **重新编译后记得再跑一次 `unlock.bat`**

用旧版 Toolkit 编译是刻意为之：PTC 官方规则保证旧版编译的 DLL 可在相同或更新的
Creo 上运行（"Creo Parametric build newer than Creo TOOLKIT build: always supported"），
反过来不保证。所以统一用 Creo 6.0 Toolkit 编译，一份 DLL 覆盖 6.0 ~ 12.0。
