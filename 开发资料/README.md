# H — Creo 工具箱（球标 / 注解 / 尺寸 / 3D / 导出）

<https://github.com/user-attachments/assets/3c779267-59cf-414f-9932-e56859ec0e5a>

在 Creo 里干活的一站式 TOOLKIT 插件。**球标编号、技术要求、重点尺寸、一键导出、  
视图动态调整、公差刷子、绘图比例、会话操作、3D 模型处理**都在一个「HA」选项卡里；  
再加上**把 Creo 原生的绘图注释命令搬进同一个页签**——出图时不用在「注释」和「HA」之间来回切。

- ✅ **一份 DLL 通吃 Creo 6.0 ~ 12.0**（用 Creo 6.0 Toolkit 编译，PTC 官方保证旧版编译的程序可在更新版本上运行）
- ✅ **加载后功能区自动出现「HA」选项卡**，不用手工拖按钮

> 只想看有什么功能、怎么用：打开 [`功能说明.txt`](功能说明.txt)，一页看完。
- ✅ **路径全自动**：插件运行时自查所在目录，整个文件夹拷到哪都能用
- ✅ **不依赖 BOM 表**：球标是纯独立符号实例，想怎么排就怎么排

## 功能一览

「HA」选项卡里共 **6 个组**，从左到右：**注释 → 会话 → 球标 → 功能 → 3D → 绘图比例**。

### 注释组（10 项，全部是 Creo 原生命令，插件零实现代码）

这不是自己写的新功能，而是**直接把 Creo 绘图「注释」页签上的按钮搬过来**——  
图标、文字、灰化状态、自带的下拉，全部由 Creo 自己提供，行为和原生页签完全一致。

| 按钮                                   | 挂的系统命令                       |
| ------------------------------------ | ---------------------------- |
| 尺寸（组里唯一的大按钮）                         | `ProCmdDwgCrStdNewRefDim`    |
| 几何公差                                 | `ProCmdDwgCrGtolSpecTol`     |
| 纵坐标尺寸                                | `ProCmdDwgCrOrdDim`          |
| 注解 ▾（4 项：分离的注解 / 偏移注解 / 顶上注解 / 引线注解） | `ProCmdDtlInsFreeNote` 等 4 个 |
| 表面粗糙度                                | `ProCmdDwgCreateSurfFin`     |
| 显示模型注释                               | `ProCmdDwgShowAllAnnots`     |
| 设置基准（基准要素符号）                         | `ProCmdDwgCrGtolSetDtm`      |
| 绘制基准目标                               | `ProCmdDwgCrGtolMakeTarg`    |
| 绘制基准平面                               | `ProCmdDwgCreateDrftDatum`   |
| 绘制基准轴                                | `ProCmdDwgCreateDraftAxis`   |

> 这些命令名是从 `<Creo 安装目录>\Common Files\text\compiled_resource\pro_default_resources.dll`>   
> 里提取的（Creo 12 有 6308 个、Creo 6 有 5201 个，**两版交集 5174 个**）。>   
> 本组用到的命令全部落在交集里，所以 **Creo 6 和 Creo 12 都能用**。>   
> 插件启动时还会用 `ProCmdCmdIdFind` 逐个验证，结果写在 `h_load.log` 里>   
> （`native cmd <名字> -> <指针> [FOUND]`），某个名字缺失会显示 `[MISSING]`。

### 会话组（2 项）

| 按钮         | 行为                   |
| ---------- | -------------------- |
| **打开工作目录** | 用资源管理器打开当前 Creo 工作目录 |
| **会话操作 ▾** | 下拉 6 项，见下            |

| 下拉项    | 行为                                                                                 |
| ------ | ---------------------------------------------------------------------------------- |
| 设置工作目录 | 弹出 Creo 原生目录浏览器，选中后切换工作目录                                                          |
| 打开模型目录 | 用资源管理器打开**当前模型**所在文件夹                                                              |
| 模型转目录  | 选一个目录，把会话里所有零件 / 装配 / 工程图备份进去（等同「文件 → 备份」）                                         |
| 批量删旧版  | 删工作目录下的 `.prt.N` / `.asm.N` / `.drw.N` / `.frm.N` / `.sec.N` / `.lay.N` / `.mfg.N` |
| 删除闲置模型 | 把没有显示在任何窗口里的模型从会话中移除                                                               |
| 清理垃圾   | 删 `.err .out .inf .idx .xpr .bak .dwl .m_p .lst .tst`                              |

> **两个删除功能有安全限制**：先扫描计数 → 消息行提示「输入 Y 回车执行，直接回车取消」→ 才动手。>   
> 范围锁死当前工作目录、只认白名单扩展名、**不递归子目录**。>   
> 「批量删旧版」额外一条：**必须同目录存在无编号的同名文件才删**——>   
> 如果某个模型只剩 `.prt.3` 而没有 `.prt`，那份 `.3` 就是唯一副本，跳过不删。

### 球标组（6 项）

| 按钮         | 行为                                                                     |
| ---------- | ---------------------------------------------------------------------- |
| **添加球标**   | 点图纸位置放一个圆圈球标，编号取当前最大号 +1。**连续放置**：放完一个直接点下一个位置，全部放完按鼠标中键 / 右键 / Esc 结束 |
| **插入球标**   | 先点放置位置，再点一个已有球标；新球标就用那个编号，它以及比它大的号全部自动 +1                              |
| **删除球标**   | 点选要删除的球标，删除后其余序号自动重排补齐                                                 |
| **重排序号**   | 把所有球标压实成 1、2、3…（补齐删除留下的空号）                                             |
| **重点尺寸**   | 连点尺寸，点一个标一个，在该尺寸文本**前面**加 ★（中键 / Esc 结束）                               |
| **取消重点尺寸** | 同样连点尺寸，把前缀里的 ★ 去掉                                                      |

**重点尺寸的约定**：已有 ★ 的自动跳过（幂等，不会叠成 ★★20）；原前缀会保留（`2x` → `★2x`）；  
参考尺寸 / 从动尺寸改不动，会提示跳过。

> 实现走的是**尺寸前缀** `ProDimensionPrefixSet`，不是改尺寸文本。前缀是独立字段，>   
> 数值文本原样保留，在 Creo 里右键 Properties 也能看到并手工改。

### 功能组（4 项）

| 按钮         | 行为                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **一键导出**   | 弹出 Creo 原生的「保存」文件浏览器：**在哪儿选目录、叫什么名字都随你**，Esc 取消。<br />· `<名字>.stp` —— 该工程图关联的 **3D 模型**（STEP）<br />· `<名字>.pdf` —— 工程图本身，**600 dpi + 单色**，导出后不弹阅读器<br />· `<名字>.dwg` —— 工程图本身（AutoCAD DWG）<br />若图纸没关联 3D 模型，只导 PDF 和 DWG 并给出提示<br />**中文名没问题**：Creo 的 DWG 导出器不认中文名，所以插件先用固定的 ASCII 临时名导出到工作目录，再由插件改名搬到你要的位置（全程 `MoveFileExW` + `MOVEFILE_COPY_ALLOWED`，宽字符）                                                                                                                                                                                                                                                                                               |
| **视图动态调整** | 分两步：**① 点按钮后弹出 Creo 原生「选择」对话框**（悬停视图会高亮并提示「数据 视图 / 视图名称」，选好后点「确定」；取消 / Esc 退出）——只接受**普通视图（General）**，投影 / 详图 / 剖视等派生视图、带子视图的视图会被拒绝并提示；**② 选中后直接移动鼠标即可全方位旋转视图**（不用按键）：**水平移 = 绕竖直轴转、垂直移 = 绕水平轴转**，即「视图方向」对话框里的 X / Y 角度；**中键 = 确定完成**，**Esc = 取消（逆序回滚，视图精确复原）**。走 `ProSelect("dwg_view")` + `PRO_SELECT_DONE_REQUIRED` 选择环境，旋转用 `ProDrawingViewOrientationFromAngleSet(dwg, view, "Horizontal"/"Vertical", NULL, 增量角)`——绕**过视图原点、相对图纸固定**的轴做**相对（增量）旋转**，**不需要基准视图，所以进入时视图原地不动（零跳变）**，可连续累积、可逆。鼠标位置用 `ProMouseTrack`，按键状态用 `GetAsyncKeyState`（`ProMouseTrack` 的按键是事件语义，不能做按住检测）。**已弃用** `ProDrawingViewOrientationFromNameSet`：它只能传模型里已保存的视图名，第一次调用就把视图强行拉走 |
| **公差刷子**   | 刷子式两步：**① 点选【源尺寸】**（Esc 退出）——选到参考 / 从动尺寸会提示重选；**② 逐个点选要接收公差的尺寸**，点一个立刻刷一个，个数不限，**中键 / Esc 结束**。刷入内容 = 公差类型（公称 / 基本 / 极限 / 正负 / 对称 / 对称上标）、上 / 下公差值、ISO/DIN 公差表、公差小数位，全部**逐项原样复制**。**不做「按名义尺寸换算极限」**：这些接口取回的是**公差值本身**，按名义值换算反而会算错。公差要可见需 config `tol_display yes`                                                                                                                                                                                                                                                                                                                                                                                          |
| **技术要求**   | 点按钮 → 弹出 Creo 原生文件浏览器（默认停在插件目录的 `templates\技术要求`）→ 选一个 `.txt` → 消息行提示点放置位置 → 左键点一下，**整个文件变成一条多行注解**插在那里，可整体拖动。空行会保留（显示为一行空白）。**每行最多 80 字**（超出截断）、**一个模板最多 64 行**。编码支持 UTF-8（带不带 BOM 都行）和 ANSI/GBK，记事本直接保存即可                                                                                                                                                                                                                                                                                                                                                                                                                                                |

### 3D 组（7 项，全部小按钮）

处理手边这个零件 / 装配本身，跟出图不用切来切去。**在工程图里点也认**——
当前窗口不是 3D 时，插件自动改用这张图关联的模型（`ProDrawingCurrentsolidGet`）。

| 按钮 | 行为 |
| --- | --- |
| **轮廓尺寸** | 弹窗列出当前模型的 **X / Y / Z 外形尺寸**（`ProSolidOutlineGet`，取不到时退回 `ProSolidOutlineCompute`），单位是模型单位 |
| **显示控制 ▾** | 下拉 4 项：**隐藏零件** / **反隐藏零件**（切换） / **全部隐藏** / **全部显示**（见下） |
| **重命名** | 消息行输入新名字 → 重命名当前模型，**同名工程图跟着改** |
| **装配着色** | 给装配里每个元件分配不同颜色（黄金角递增，相邻色差最大）；同一零件的多个实例同色。想保留记得存盘 |
| **零件着色** | 给当前模型整体涂一个随机颜色 |
| **清除着色** | `ProMdlVisibleSideAppearancepropsSet(…, NULL)` = 恢复默认外观 |
| **原位打开** | 选一个元件，**按装配当前视角**把它单独打开（先 `ProViewMatrixGet` 记矩阵 → `ProMdlDisplay` → `ProViewMatrixSet` 套回去） |
| **批量备份** | 选目录 → `ProMdlnameBackup`，当前模型**连同它引用的全部子模型**一起备份 |

**显示控制的四项**：

- **隐藏零件** —— 把选中的藏起来（`ProModelitemHide`）
- **反隐藏零件** —— 切换：`ProModelitemIsHidden` 判断后，隐藏的显示出来、显示的隐藏掉
- **全部隐藏 / 全部显示** —— 不用选，`ProSolidFeatVisit` 遍历模型里所有特征逐个 `ProModelitemHide` / `Unhide`（Creo 没有 HideAll / UnhideAll 的 C 接口）

> **选择怎么做**：先**在图形区选中**要处理的对象，再点按钮 —— 插件会直接读 Creo 的选择缓冲区，
> 不再弹选择。没预选时才进入交互选择，此时消息行会提示"点选对象，中键确认"。
> 这样和 Creo 自身"先选后点"的习惯一致。

> **3D 模式下的页签**：除了绘图页签里的这个 3D 组，`toolkitribbonui.rbn` 里还给
> **零件 / 装配 / 钣金** 三个窗口各声明了一个「HA」页签（**会话 + 3D** 两个组，顺序和绘图页签一致），
> 挂在这三个容器上：
>
> | 模式 | 容器名（`*_adb_cat`） |
> | --- | --- |
> | 零件 | `prt_main_adb_cat` |
> | 装配 | `asm_main_adb_cat` |
> | 钣金零件 | `prt_smt_main_adb_cat` |
> | 绘图 | `drw_main_adb_cat`（完整 6 组） |
> | 未打开模型（启动页） | `main_adb_cat` |
>
> 这五个名字是从 Creo 6.0.2.0 与 Creo 12.4.0.0 两套安装目录的资源 DLL 里
> 用 `_adb_cat` 结尾的正则捞出来的（Creo 6 共 341 个、Creo 12 共 368 个），
> 上面这五个**两版都有**，所以跨版本通用。容器名对不上时 Creo 只是忽略那一条
> `ribbonList`，不影响别的模式的页签。

## 快速安装（3 步，1 分钟）

1. **放置文件**：把整个 `H` 文件夹复制到纯英文、无空格的目录，例如 `D:\H`     
   （放在别的位置先双击运行一次 `setup.bat`，它会自动修正注册文件里的路径）
2. **注册插件**：记事本打开 Creo 的 `config.pro`，最后加一行：
   ```
   protkdat D:\H\H.dat
   ```
   （放在别的目录就把路径换成实际位置；也可以在 Creo 里     
   工具 → 辅助应用程序 → 注册 → 选中 H.dat → 启动，但只当次生效）
3. **重启 Creo**。打开任意工程图，选项卡栏最右侧出现「**HA**」选项卡，装好了。

> 如果点按钮提示"未找到球标符号文件"：看插件目录下自动生成的 `h_load.log`，>   
> 里面写明了原因（符号文件是否缺失、三条加载路径各自的返回码），把日志发给作者即可定位。

## 技术要求模板文件夹

`templates\技术要求\` 里每个 `.txt` 都会出现在选择列表里，文件名就是列表里看到的名称  
（建议用 `01_`、`02_` 开头控制顺序）。**一行就是注解里的一行**，直接往这个文件夹里丢 txt 就行。

- 目录不存在时插件会自动创建；模板目录跟着插件文件夹走，换电脑不用改任何设置
- 包里自带 30 多个常用模板（车件 / 钣金 / MIM / 压铸锌合金 / 弹簧 / 工艺路线 / 齿轮参数…），按自己的工艺改就行
- 编码 UTF-8 或 ANSI(GBK) 都能读，行尾 CRLF / LF 都行
- ⚠ 每行超过 80 字会被截断，超过 64 行会被截掉——这是 Creo 注解单行的宽度限制（`PRO_LINE_SIZE = 81`）

## 故障排查

插件目录下每次启动都会写 `h_load.log`，关键行：

- `ProCmdActionAdd(...) -> 0`：0 = 命令注册成功（返回 -28 也不影响按钮功能，可忽略）
- `ProRibbonDefinitionfileLoad(...) -> 0`：功能区加载成功。    
  `-4` = rbn 文件没找到（确认 `text\ribbon\toolkitribbonui.rbn` 存在）；    
  `-16` = 格式不对（按下方说明用 Creo 导出一份正规的）
- `native cmd <命令名> -> <指针> [FOUND] / [MISSING]`：注释组那 14 个原生命令名的存在性自检。    
  全是 `[FOUND]` 说明这批按钮在当前 Creo 版本上一定可用；出现 `[MISSING]` 说明该版本没有这个命令
- `HLoadSymbol: ... EXISTS / MISSING!`：符号文件在不在。`MISSING!` 说明发出去的包不完整，少了 `symbols` 文件夹
- `HLoadSymbol: OK via [1|2|3]`：符号最终走通哪条加载路（1=pro_symbol_dir 相对路径，2=复制到工作目录，3=绝对路径兜底）
- `HTechReqAct: file open -> 0`：技术要求选了模板文件（`-1` = 用户取消）；    
  `cp=/bom=/lines=` 是识别出的编码、有无 BOM、读到的行数；    
  `noteCreate -> 0` 表示注解建好了
- `HKeyDimAct / HKeyDimMark`：重点尺寸的逐步结果，含 `/已跳过/失败/视图重生成/前缀旧长度/写入结果`
- `HExportAct: ...`：一键导出的逐步返回码。`STEP -> 0`、`DWG -> 0`、`PDF -> 0` 是成功；    
  `ProFileMdlnameSave -> 0` 是浏览器正常返回（`-1` = 用户取消），    
  `HExport: moved -> <完整路径>` 表示临时文件已改名搬到你要的位置，    
  `HExport: MISSING source for <路径>` 才是那一个文件没落地；    
  行尾 `license_missing=1` 说明缺少对应导出模块的授权

常见现象：

- **提示"未找到球标符号文件"**：把 `symbols\123.sym` 复制到 Creo 当前工作目录，    
  或在 `config.pro` 里设 `pro_symbol_dir D:\H\symbols`（已有该行就别加第二行，直接把符号放进它指向的目录）
- **提示"请在工程图界面执行此命令"**：这些命令只能在工程图（Drawing）模式下用
- **重点尺寸的 ★ 显示成方框**：说明当前绘图字体没有 ★ 字形。Creo 默认的 CJK 回退一般没问题，    
  真遇到就在 `config.pro` 里换一款支持中文的绘图字体，或改用 `◆`
- **功能区没有「HA」选项卡**：先确认工程图模式（选项卡只在工程图出现）；    
  仍没有则按 [ Creo 自定义功能区 ] 导出正规 rbn：`config.pro` 加    
  `tk_enable_ribbon_custom_save yes` 重启 → 文件 → 选项 → 自定义功能区 →    
  新建选项卡/组 → 命令来源选「所有 ProTk 命令」添加按钮 →    
  导入/导出 → 保存辅助应用程序用户界面 → 把生成的 rbn 复制覆盖 `text\ribbon\` 下同名文件
- **页签/组名显示成英文键名（如 `H_Title`、`H_Annot`、`H_Func`）**：说明功能区页签和组的    
  **标签消息文件 `text\<locale>\ribbonui.txt` 缺失或没刷新**。Creo 解析页签/组标签只认这个专用文件    
  （命令标签才走 `h_msg.txt`），键名就是 rbn 里的 `mLabel` 值。    
  （含中文内容的用 UTF-8 + BOM；英文那份纯 ASCII 无 BOM；行尾是 LF）

## ⚠️ 发给别人之前：必须先解锁

别人打开 Creo 弹出「**应用程序 "H" 在分配到您的位置之前未被解锁**」，  
不是插件写错，是 PTC 对 TOOLKIT 插件的统一规定：编译出的 DLL 默认锁定，  
只有装了 Creo Parametric TOOLKIT 开发许可的电脑才能加载，分发前必须解锁。

1. 完全退出 Creo（任务管理器确认没有 `xtop.exe`）
2. 双击插件目录里的 `unlock.bat`，看到「解锁成功」即可
3. 打包发给别人

两条铁律：

- **每次重新编译 H.dll 之后都要重新跑一次 unlock.bat**（链接时会重新写入锁定标记）
- **解锁之后不要再改动 H.dll 哪怕一个字节**（改动后会被重新当成锁定状态）

解锁会占用一个 TOOLKIT 许可几秒钟（最长 15 分钟），正常现象。

## 球标符号版本注意（`symbols\123.sym`）

Creo 的文件只**向上兼容**：新版能读旧版，旧版读不了新版，`.sym` 一模一样。

- 本插件的 `123.sym` 用 **Creo 6.0.2.0** 存出（格式级别 3700），Creo 6~12 全能读
- **千万别用新版 Creo 打开它再保存** —— 保存会升级成新版格式，对方的 Creo 6 立刻读不了
- 以后换符号同理：发给谁，就用**对方那个版本或更老**的 Creo 去存

## 重新编译（可选）

需要 Visual Studio 2022（含 C++ 生成工具）和 Creo 6.0 的 Toolkit 开发包  
（Creo 安装介质自带，没勾「API Toolkits / Creo Parametric TOOLKIT」组件的话用安装程序补装）：

1. 把 `makefile` 里 `CREO6_SDK` 改成 Toolkit 根目录（含 `includes` 与 `x86e_win64\obj`）
2. 双击 `build.bat`（或 `nmake /f makefile`）
3. **重新编译后记得再跑一次 `unlock.bat`**

用旧版 Toolkit 编译是刻意为之：PTC 官方规则保证旧版编译的 DLL 可在相同或更新的  
Creo 上运行（"Creo Parametric build newer than Creo TOOLKIT build: always supported"），  
反过来不保证。所以统一用 Creo 6.0 Toolkit 编译，一份 DLL 覆盖 6.0 ~ 12.0。
