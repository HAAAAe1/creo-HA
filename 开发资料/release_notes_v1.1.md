# H v1.1 — Creo 工具箱

装好后 Creo 顶部多一个 **HA** 页签。工程图、零件、装配、钣金都能用。

## 安装（三步）

1. 把整个 `H` 文件夹放到 `D:\H`，打开能看到 `H.dll` 就对了。路径里不要有中文和空格。
2. Creo → 文件 → 选项 → 配置编辑器，在最后加一行：`protkdat D:\H\H.dat`，保存。
3. 关掉 Creo 重新打开。

> **换盘了，就换成你文件的实际位置！**
> 换盘后先双击一次 `setup.bat`，它会记住新位置。

看不懂字就看包里的 `安装步骤.png`（三张图）。

## 本次更新

- **全部 59 个按钮挂上图标**：从 Creo 自带资源挑 35 组，输出 20×20 / 32×32 两档共 70 个 PNG，`ProCmdIconSet` 逐个登记。
- **修好按钮不显示图标**：rbn 里每个命令原本写成 `SmallTextOnly`（= 小按钮·无图标），全部改为 `Small`。
- **修好按钮没有文字**：`ProCmdDesignate` 第 4 个参数传了空串，被当成消息键去查，一处查不到就整条登记作废（返回 -28）。补 `H_CmdDesc` 键后标签恢复。
- **基准组**新增 Creo 原生 `修剪` / `投影` / `扫描`（命令名从 trail 反查：`ProCmdFtTrim` / `ProCmdFtProject` / `ProCmdFtLoft`）。
- **工程图**新增 `原位打开`（选一个视图，按该视图方向把 3D 单独开窗）、`打开 3D`。
- **模型信息**新增 `复制名称`：装配复制装配名、零件复制零件名、图纸复制图纸名，不用先选中。
- **方程曲线**对话框常驻提示：方程曲线是开放样条，要修剪先投影。
- **发布包整理**：源码、makefile、build.bat、LICENSE、README 全部收进 `开发资料\`，根目录只剩装插件要用的东西。

## 功能一览

| 分组 | 内容 |
|---|---|
| 标注（9） | 尺寸、几何公差、纵坐标尺寸、注解（分离/偏移/顶上/引线）、表面粗糙度、显示模型注释、设置基准、基准目标、基准平面、基准轴 |
| 球标（6） | 添加球标（编号自动 +1，连续放置）、插入球标（顺延后续编号）、删除球标（自动补齐）、重排序号、重点尺寸（尺寸前加 ★）、取消重点尺寸 |
| 工程图（5） | 原位打开、打开 3D、公差刷、技术要求（txt 模板 → 多行注解）、视图动态调整（移鼠标转视图，Esc 还原） |
| 比例 | 1:1 / 1:2 / 1:3 / 2:1 / 3:1 / 4:1，更多 20 档，自定义（1:2.5、0.4、1/3） |
| 模型信息（3） | 重命名、复制名称、轮廓尺寸 |
| 会话操作（8） | 打开工作目录、设置工作目录、打开模型目录、模型转目录、批量备份、批量删旧版、删除闲置模型、清理垃圾 |
| 着色（2） | 随机着色（同零件同色）、清除着色 |
| 视图（2） | 原位打开（按当前视角单独开元件）、视图正归位 |
| 简化助手（5） | 隐藏、显示、反隐藏零件、全部隐藏、全部显示 |
| 基准（4） | 方程曲线、修剪、投影、扫描 |
| 导出（1） | 一键导出图纸：`.stp` + `.pdf`（600dpi 单色）+ `.dwg` |

详细说明见包内 `功能说明.txt` / `功能说明_A4.png`。
